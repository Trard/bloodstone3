# BloodstoneSyringe 1.0.0

Плагин для **Paper / Folia 1.21.11**, Java **21**. Внешние плагины не нужны.

## Установка

1. Поместите `BloodstoneSyringe-1.0.0.jar` в `plugins/` и перезапустите сервер.
2. Подключите игрокам полный `BloodStone-syringe-1.21.11.zip` из комплекта
   либо объединённый ресурспак из репозитория Bloodstone.
   ZIP устанавливается как обычный ресурспак; распаковывать его клиенту не нужно.
3. Выдайте шприцы: `/syringe give Ник 8` (из консоли без начального `/`).
4. Держите шприц в **основной руке**. **ПКМ по игроку** — укол ему,
   **Shift + ПКМ** по воздуху, блоку или сущности — укол себе.

Без ресурспака функционал работает, но вместо шприца видна удочка с морковкой.
Для автоматической загрузки разместите ZIP на прямой HTTPS-ссылке и укажите
её в `resource-pack` файла `server.properties`, а SHA-1 ZIP — в `resource-pack-sha1`.
Существующий серверный ресурспак следует заменить объединённым ZIP, в котором
сохранены все прежние ресурсы Bloodstone и его версионные overlays.

## Правила по умолчанию

- Один успешный укол расходует один шприц, включая творческий режим.
- Стопка до 64. Команда выдачи принимает 1–2304; лишнее при полном инвентаре выпадает рядом.
- Интервал между уколами одного применяющего игрока — 1,5 секунды.
- Дальность — 3 блока; нужен прямой обзор. Зрители и мёртвые игроки исключены.
- До передозировки: 50% положительный / 50% отрицательный эффект.
- С **4-го укола за последние 60 секунд**: **75% дебаф / 25% баф**.
  Каждый успешный укол выбирает один эффект; внутри группы шансы равны.
- Уколы от разных игроков и уколы себе суммируются **у получателя**.
  Выход и рестарт не сбрасывают окно; смерть очищает его.
- При передозировке эффект обычно сильнее/дольше, появляется особый звук.
- Каждый укол сопровождается взмахом руки, частицами, звуком щелчка/впрыска
  и сообщением с названием эффекта и длительностью.
- При отклонении эффекта другим плагином или уже действующем более сильном
  эффекте шприц и счётчик уколов сохраняются без изменений.
- Пустая модель тоже включена в ресурспак как отдельный декоративный вариант.
  Использованный шприц расходуется; отдельная заправка/крафт пока не предусмотрены.

## Команды и права

| Команда / право | Назначение |
| --- | --- |
| `/syringe give <игрок> [количество]` | Выдать готовый функциональный предмет |
| `/syringe reload` | Применить `plugins/BloodstoneSyringe/config.yml` без перезапуска |
| `bloodstonesyringe.admin` | Команды выдачи и reload; по умолчанию OP |
| `bloodstonesyringe.use` | Использовать шприцы; по умолчанию все игроки |

В конфиге редактируются шансы, порог, окно, задержка, дальность, звук/частицы,
расход, списки эффектов, длительности и уровни. Ошибочный reload сохраняет
предыдущие рабочие настройки. Уровень 1 соответствует I, 2 — II.

## Модель и совместимость

- База: `minecraft:carrot_on_a_stick`.
- CustomModelData: `floats: [21011.0]`.
- Item model: `bloodstone:tools/syringe/default/syringe`.
- Для стопок удалены компоненты `max_damage` и `damage` базового предмета.
- Метка `bloodstonesyringe:syringe` в PDC отличает настоящий шприц от декорации.
  Обычная `/give` только с моделью не даёт функционал; используйте `/syringe give`.
- На Folia выдача выполняется через `EntityScheduler` получателя. Уколы проходят
  на потоке региона взаимодействия; доступ к обоим игрокам проверяется через
  `Bukkit.isOwnedByCurrentRegion`. При переходе в другой регион укол отклоняется
  без расхода — его можно повторить. Между регионами не читаются чужие инвентари.
- Учитываются отменённые взаимодействия с сущностями/блоками и выключенный PvP мира.
  Shift + ПКМ по воздуху обрабатывается даже при стандартной отмене Minecraft
  для предмета без ванильного действия. Для правил приватов и специальных PvP-зон
  другие плагины могут отменять `ru.bloodstone.syringe.SyringeInjectEvent`.
  Это событие вызывается до изменения эффекта, истории, кулдауна и предмета.

Изменение `custom-model-data` требует соответствующей правки ресурспака, если
используется резервный выбор только по CMD; явный `item.model` работает независимо.

## Сборка и проверка

Из каталога плагина: `mvn clean verify` (Maven 3.9+, JDK 21).
Результат: `target/BloodstoneSyringe-1.0.0.jar`.

Автотесты JUnit + MockBukkit проверяют загрузку, конфиг, метку предмета, уколы,
расход, повторные события, основную/вторую руку, отмену, получателя, передозировку,
границу 60 секунд, точное распределение шансов и отказ доступа к чужому региону.
MockBukkit не заменяет настоящий сервер Folia. Компоненты модели проверяются
перед копированием ItemMeta, поскольку текущая копия damageable ItemMeta в
MockBukkit не сохраняет CMD/item_model.

После установки проверьте с двумя игроками: внешний вид в руке/инвентаре,
ПКМ по другому, Shift + ПКМ по воздуху и блоку, четыре успешных укола, обычную
удочку, отмену взаимодействия плагином приватов и работу в разных регионах Folia.
Живая игровая проверка клиента/сервера в этой сборке не выполнялась.

Форматы и API сверены с [документацией Paper/Folia](https://docs.papermc.io/paper/dev/folia-support/)
и [описанием Minecraft 1.21.11](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-11).
