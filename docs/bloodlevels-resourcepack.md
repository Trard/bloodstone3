## Шрифты и совместимость

`minecraft:default` подключает только `bloodlevels:icons_default`, где значки используют свободные коды `U+E060–U+E069` и `U+E070–U+E075`.
Старые коды пересекаются с `minecraft:inventoryviews`, поэтому подключать `bloodlevels:icons` напрямую в стандартный шрифт нельзя.

Отдельный `bloodlevels:icons` сохраняет исходные символы и через reference поддерживает новые. Шрифты `bloodlevels:menu_progress` и `bloodlevels:menu_premium_progress` также поддерживают обе версии кодов.
Так сохраняется совместимость с меню, использующим старые коды с явно заданным шрифтом. Повторение кодов в отдельных шрифтах намеренное; старые символы BloodLevels не экспортируются в `minecraft:default`.
Шрифт фонов `bloodlevels:menus` перенесён без изменений и в стандартный шрифт не подключается.

Фоны производятся из сохранённых `levels_001.png`, `levels_012.png` и `levels_013.png`: стираются только полосы с номерами, остальные пиксели не меняются.
`python3 scripts/update_bloodlevels_layouts.py` повторяет эту операцию, обновляет маски, шрифты и ссылки без сборки ZIP. Старые 112 пронумерованных фонов остаются для совместимости.

Обычные номера бесплатной линии находятся на Y=74, нижние трёхзначные — Y=103; Premium — Y=141. После Premium используются шрифты `menu_numbers_free_only` и `menu_numbers_free_only_lower` с Y=110 и Y=139.
Полоса бесплатного прогресса также сдвинута на 36 пикселей через `menu_progress_free_only`; премиум-прогресс на этих страницах не выводится.
Маска надписи инвентаря использует слот 48 на первых двух оформлениях и слот 39 в `free-only`, с компенсацией GUI translation `[18, -35, 0]`.
`level-labels.draw-premium-slots: false` отключает дополнительные ячейки из шрифта: они уже присутствуют в нужном количестве на фоне.

В проекте BloodLevels синхронизированы `resource-pack/source/layouts`, ресурсы и `resource-pack/build.ps1`. Загрузчик подставляет новые секции оформления в старые RP-конфиги, если эти секции отсутствуют; файл на сервере не перезаписывается.
Проверены ссылки ресурсов, отсутствие повторных символов, точность удаления цифр и статические предпросмотры страниц 1/11/12/13/112. Фактическое отображение масок и шрифтов в клиенте требует проверки после установки обновлённого плагина и ресурспака.

Модели масок этих страниц имеют GUI translation `[18, -35, 0]`, чтобы после переноса предмета маска оставалась поверх стандартной надписи инвентаря.

`--dry-run` проверяет входные файлы без записи; `--output-dir /tmp/bloodlevels-preview` создаёт только предпросмотр фонов, не изменяя маски пака.

## Повторяемые проверки

Скрипты работают локально, не собирают пак, не меняют его файлы и не обращаются к серверам. Для проверки BloodLevels и тестов нужны Python 3.10+, Pillow и PyYAML; проверка символов использует только стандартную библиотеку Python.
Команды ниже запускаются из корня репозитория; сами скрипты также находят корень по своему расположению, если запускать их по абсолютному пути.

```bash
# Все шрифты пака: отдельные области символов, reference, циклы и активные оверлеи.
python3 scripts/check_font_symbols.py --format 75

# Только один шрифт; --font можно повторять. Прежний --font-root также поддерживается.
python3 scripts/check_font_symbols.py --font bloodlevels:icons

# Проверка импортированных ресурсов, обеих версий символов, конфигурации и 112 страниц меню.
python3 scripts/check_bloodlevels.py

# Полная проверка исходного архива и внешних vanilla-ресурсов по локальному клиентскому JAR.
python3 scripts/check_bloodlevels.py \
  --source-zip /home/trard/dev/resourcepacks/BloodLevels-devtest-e68eb30a9ed9.zip \
  --vanilla-jar /mnt/c/Users/trard/AppData/Roaming/ModrinthApp/meta/versions/1.21.11/1.21.11.jar

# Проверка самих валидаторов на корректных и намеренно повреждённых временных данных.
python3 scripts/test_resourcepack_validation.py
```

При ошибках скрипты возвращают код 1. Без `--source-zip` не подтверждается соответствие исходному архиву; при сравнении неизменённых JSON допускается только нормализация CRLF/LF, выполняемая Git, а PNG сравниваются побайтово. Без `--vanilla-jar` внешний `minecraft:item/generated` считается известной vanilla-зависимостью и это явно отмечается в выводе.
`--config PATH` позволяет проверить другую локальную копию `resource-pack.yml`, например скачанную с сервера. Старый конфиг со значками `U+E520…` такую проверку не пройдёт: для legacy-плейсхолдеров требуется новый конфиг.
`--format` выбирает оверлеи для целого номера формата; успешная статическая проверка не подтверждает поддержку всех возможностей пака старыми клиентами.

### Исправленные существующие конфликты

Полная проверка всех шрифтов выявила конфликты, существовавшие в HEAD до импорта BloodLevels; они исправлены отдельными локальными изменениями:

- `minecraft:suffixes`: `U+E0D3` используется одновременно для `suffixes/en/glsser.png` и `suffixes/aurad_large_gear_1.png`.
- `minecraft:suffixes`: `U+E0D4` используется одновременно для `suffixes/en/prezident.png` и `suffixes/aurad_large_gear_2.png`.
- `maceroulette:gui/profile/main`: `U+E020` дважды назначен одной картинке `equality_yang.png`.

Английские суффиксы сохранили коды `U+E0D3` и `U+E0D4`. Большие шестерёнки перенесены на свободные коды: `aurad_large_gear_1.png` — `U+E0E8` (), `aurad_large_gear_2.png` — `U+E0E9` ().
В шрифте профиля maceroulette удалён один идентичный блок `U+E020`; оставшийся блок сохраняет прежнюю картинку и метрики. Общая проверка теперь проходит.
Текущий локальный BloodDonate использует для шестерёнок отдельный шрифт `blooddonate:particles` с кодами `U+E000/U+E001`; его ресурсы не изменены.
Если где-либо ещё используется старый AuraD с кодами `U+E0D3/U+E0D4` для больших шестерёнок в `minecraft:suffixes` или стандартном шрифте, соответствующий потребитель должен перейти на `U+E0E8/U+E0E9`. Серверы и исходники плагинов при этом исправлении не изменялись.
Скрипты проверяют перечисленные структуры и связи; они не запускают рендерер Minecraft и не подтверждают фактическое применение конфигурации на сервере или совместимость с дополнительными клиентскими паками.
