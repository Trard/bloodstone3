# Ресурсы Вторжения

Основной пак содержит шрифты HUD, индикаторы захвата, флаги шести фракций и модель коробки снабжения. Прежние ресурсы других режимов, переводы, шейдеры и провайдеры шрифтов сохранены.

## Сборка для сервера Вторжения

Начиная с BloodInvasion 1.9.39 кастомный интерфейс выводится отдельным слоем из action bar. Плагин не отправляет свою ванильную полоску. Все боссбары других плагинов, включая белые, сохраняются: подмен текстур `boss_bar` больше нет ни в основном паке, ни в отдельной сборке.

Обновить нужно и JAR, и РП. В `1.21.11` шейдер перемещает только символы специальных шрифтов `bloodinvasion:overlay/*` в верхнюю часть экрана. Обычные шрифты, буквы над точками и существующие эффекты BloodStoneEvents не меняются. Action bar продолжает показывать сообщения, очки и таймер возрождения снизу. Справа сверху добавлен исходный PNG Bloodstone с подписью `bloodstone.gg`; на узком интерфейсе он опускается ниже ряда точек, чтобы не перекрывать его.

Для Вторжения соберите полный пак одной командой; дополнительных паков на клиенте подключать не нужно:

```sh
python scripts/build_invasion_resourcepack.py --output resourcepack-invasion.zip
```

Обе команды сборки включают одинаковые игровые ресурсы и версионные overlays. Скрипт Вторжения работает также на Windows и кладёт в ZIP только файлы РП. `pack.mcmeta` и workflows не изменяются. Публикация исходников выполняется без тегов.

При изменении исходных шрифтов выполните `python scripts/build_invasion_overlay_fonts.py`. PNG с логотипом генерируется командой `python scripts/build_invasion_branding.py` (нужен Pillow). Шейдер проверяется на GPU: `python scripts/test_invasion_overlay.py --client <1.21.11-client.jar> --samples <plugin-hud-samples> --output <previews>` (Pillow, numpy, moderngl).

## Символы фракций

Для чата используется `minecraft:invasion_factions`, подключённый к стандартному шрифту. Для HUD применяется отдельный размер из `minecraft:invasion_faction_hud`.

| Фракция | Код | Символ |
| --- | --- | --- |
| Пепельные | U+E0E2 |  |
| ЧВК «Киндер» | U+E0E3 |  |
| Торговая Коалиция | U+E0E4 |  |
| Celestials | U+E0E5 |  |
| АКС | U+E0E6 |  |
| Акбар | U+E0E7 |  |

Буквы над точками остаются белыми; цвет фракции заполняет рамку по мере захвата. Текстуры иконок сохраняются без сглаживания. Позиции букв с диакритикой в шрифтах HUD учитывают исходный ascent.
