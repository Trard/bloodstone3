# Ресурсы Вторжения

Основной пак содержит шрифты HUD, индикаторы захвата, флаги шести фракций и модель коробки снабжения. Прежние ресурсы других режимов, переводы, шейдеры и провайдеры шрифтов сохранены.

## Сборка для сервера Вторжения

Белая ванильная полоска должна быть скрыта под кастомным HUD Вторжения. Подмена её текстур в основном паке затронула бы белые боссбары всех остальных режимов. Поэтому две прозрачные текстуры находятся в `variants/invasion`, вне активных ресурсов основного пака.

Для Вторжения соберите полный пак одной командой; дополнительных паков на клиенте подключать не нужно:

```sh
python scripts/build_invasion_resourcepack.py --output resourcepack-invasion.zip
```

Для остальных серверов используйте обычную сборку `scripts/build_resourcepack_zip.py` или существующую сборку основного пака. Скрипт Вторжения использует те же ресурсы и версионные overlays, добавляя только две прозрачные текстуры боссбара. Основной `pack.mcmeta` и workflows не изменяются.

## Символы фракций

Для чата используется `minecraft:invasion_factions`, подключённый к стандартному шрифту. Для HUD применяется отдельный размер из `minecraft:invasion_faction_hud`.

| Фракция | Код | Символ |
| --- | --- | --- |
| Пепельные | U+E0E2 |  |
| ЧВК «Киндер» | U+E0E3 |  |
| Торговая Коалиция | U+E0E4 |  |
| Celestials | U+E0E5 |  |
| АКС | U+E0E6 |  |
| Акбар | U+E0E7 |  |

Буквы над точками остаются белыми; цвет фракции заполняет рамку по мере захвата. Текстуры иконок сохраняются без сглаживания. Позиции букв с диакритикой в шрифтах HUD учитывают исходный ascent.
